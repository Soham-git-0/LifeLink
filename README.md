# LifeLink — Blood & Organ Donor Management System

Frontend starter for the DBMS project presented in the project PPT.

## Tech stack
- React (frontend)
- Flask + Python (backend — next phase)
- MySQL (database — next phase)
- MySQL Workbench (ER/schema modelling)
- Postman + SQL tests
- Git + GitHub

## Run the frontend

Requirements: Node.js and npm.

```bash
cd blood-organ-system
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Current phase
The React shell includes the dashboard and navigation for all proposed modules. Data is currently mock data so the interface can be developed before connecting Flask and MySQL.
